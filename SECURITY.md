# Sécurité

Glimio est un outil local en développement. Le serveur web local ne fournit pas d'authentification : ne l'expose pas sur un réseau non fiable. N'ouvrez pas un accès public ou LAN sans ajouter une couche d'authentification et des contrôles de sécurité adaptés.

Ne publiez pas d'audio, de transcriptions, de clés API, de jetons ou de chemins privés contenant des informations personnelles dans les tickets Git.

Pour signaler un problème de sécurité, contactez directement le mainteneur du dépôt avant de créer un ticket public. Aucun SLA de sécurité n'est actuellement garanti pour les versions `0.x`.
